# 実装計画: グループ削除機能

## 追加機能の概要
グループの作成者（オーナー）だけがグループを削除できる機能を追加します。
削除時には、確認ダイアログを表示し、承諾された場合にFirestoreからデータを削除します。

## 変更内容

### 1. フックの拡張
`src/features/groups/hooks/useGroupDetail.ts`
- `deleteGroup` 関数を追加します。
- **処理内容**:
    - `groupMembers` コレクションから、該当グループのメンバーデータを全て取得し、バッチ削除します。
    - `groups` コレクションから該当グループのドキュメントを削除します。

### 2. UIの更新
`app/groups/[id].tsx`
- オーナー（`isOwner` が true）の場合のみ、グループ設定または下部に「グループを削除する」ボタンを表示します。
    - デザイン: 赤文字（destructive）のボタンまたはテキストリンク。
- 削除ボタン押下時に `Alert.alert` で確認を表示します。
- 削除完了後、`router.replace('/groups')` 等でグループ一覧に戻ります（※パスは要確認、`router.back()` だと不十分な場合があるため）。

## 検証計画
- シミュレータにて、グループオーナーでログインし、削除ボタンが表示されることを確認。
- 削除実行後、グループ一覧に戻り、該当グループが消えていることを確認。
- 別のユーザー（メンバー）でログインし、削除ボタンが表示されないことを確認。
