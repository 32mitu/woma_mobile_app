# グループ削除機能の実装確認

## 変更内容
- [x] `useGroupDetail.ts` に `deleteGroup` 実装
  - Firestoreの `groups` および `groupMembers` コレクションから削除する処理を追加した。
- [x] `GroupDetailScreen` に削除ボタン追加
  - グループオーナー (`isOwner`) の場合のみ、削除ボタンが表示されるようにした。
  - 削除前にアラートで確認を行い、完了後にプロフィール画面へ遷移するようにした。
- [x] 既存バグ修正
  - メンバー数表示で存在しないプロパティ `members` を参照していた箇所を `memberIds` に修正した。

## 検証結果
- [x] オーナーによる削除
  - コード上、`isOwner` フラグによりボタン表示制御を確認。
  - `deleteGroup` 関数内でバッチ処理による削除を確認。
- [x] メンバーによる削除不可確認
  - `isOwner` が false の場合、削除ボタンの代わりに脱退ボタンが表示されるロジックを確認。
