# バッジ表示不具合の修正計画

## 現在の問題点
ユーザーより「バッジが表示されない」との報告あり。
調査の結果、バッジ付与の前提となる「ストリーク（継続日数）」計算ロジックに潜在的な不具合を発見。
`src/utils/gamificationUtils.ts` 内の `calculateStreak` 関数において、比較対象となる「昨日」の日付を計算する際に、引数として渡された `today`（基準日）を使わず、現在時刻 `new Date()` から計算している。
これにより、日付変更直後など特定のタイミングで、`today` と `new Date()` の日付がずれ、ストリークが正しく加算されない（＝バッジ条件が満たされない）可能性がある。

## 変更内容

### 共通ユーティリティ (`src/utils/gamificationUtils.ts`)
- `calculateStreak` 関数を修正する。
- `new Date()` を使用して昨日を計算するのではなく、引数の `today` 文字列をパースして昨日を算出するように変更する。これにより、入力に対して常に一貫した結果を返す純粋関数とする。

### 詳細手順
1. `today` ("YYYY-MM-DD") をパースして Date オブジェクトを生成する処理を追加。
2. その Date オブジェクトから1日引いた日付を `yesterdayStr` として生成する。
3. これにより、確実に `today` の前日と比較判定が行われるようにする。

## 検証方法

### ユニットテスト/動作確認
- コード変更後、以下のシナリオで動作を確認する（実際のアプリ操作またはログでの確認）。
    1. 最終記録日が「昨日」であるユーザーで記録を行う -> ストリークが +1 されること。
    2. ストリークが 3, 7 に達した際に、対応するバッジが付与されること。
- 今回は自動テスト環境が整備されていないため、修正ロジックが論理的に正しいことをコード上で確認し、ユーザーに動作確認を依頼する。
